# Inventory Management System (C++)

A simple CLI program to manage inventory items: add, delete, update, display, and search items by code.

## Features
- Add an item (code, name, quantity, unit, price)
- Delete an item by code
- Update an item by code
- Display all inventory items
- Search an item by code

## Tech Stack
- C++ 
- Terminal-based input/output (CLI)
